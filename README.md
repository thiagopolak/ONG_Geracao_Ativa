## 🚀 Sobre o Projeto

Este repositório contém o projeto final da disciplina **Desenvolvimento Front-end para Web**, do curso de **Bacharelado em Ciência da Computação** pela **Universidade Positivo**.

O desafio foi desenvolver uma **plataforma web completa e profissional** para uma ONG fictícia: **Geração Ativa**.  
O site é composto por **três páginas institucionais** (Início, Projetos e Cadastro) e aplica, de forma integrada, todos os conceitos estudados nas quatro unidades da disciplina.


➡️ **[Acesse o site publicado via GitHub Pages](https://thiagopolak.github.io/ONG_Geracao_Ativa/index.html)**

## 📌 Descrição do Projeto

O site da ONG Geração Ativa foi desenvolvido para:
- Apresentar a ONG, sua missão, visão e valores.
- Listar os projetos sociais ativos.
- Permitir cadastro de voluntários e doadores.
- Garantir acessibilidade, responsividade e performance para todos os usuários.

**Páginas principais:**

* **index.html**	Página inicial com missão, valores e informações de contato.
* **projetos.html**	Listagem de projetos sociais e oportunidades de voluntariado.
* **cadastro.html**	Formulário completo com validação de dados para voluntários e doadores.

## 🛠️ Tecnologias Utilizadas
- **HTML5** — estrutura semântica e acessível   
- **Git & GitHub** — versionamento e hospedagem  
- **GitHub Pages** — deploy gratuito do site
